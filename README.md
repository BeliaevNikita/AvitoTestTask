# Avito Data Science Bootcamp 2026

Решение тестового задания для Data Science Bootcamp 2026 от Avito.

## Файлы

```text
AvitoTestTask/
├── metric.py
├── requirements.txt
├── solution.ipynb
└── README.md
```

- `solution.ipynb` — основное решение задачи.
- `metric.py` — реализация официальной метрики `Precision @ Recall >= 0.70`.
- `requirements.txt` — список зависимостей, необходимых для запуска решения.

## Запуск

Для запуска решения откройте `solution.ipynb` и последовательно выполните все ячейки ноутбука.

Установка необходимых зависимостей из `requirements.txt` выполняется непосредственно в одной из первых ячеек ноутбука.

`metric.py` должен находиться в одной директории с `solution.ipynb`, так как он используется ноутбуком для расчёта официальной метрики.
